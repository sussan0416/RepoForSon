📖 つかいかた

① ステージ プログラム（うえの わく）

  • apple(x, y) — りんごを おく
  • orange(x, y) — みかんを おく
  • melon(x, y) — メロンを おく
  • kame(x, y) — かめを おく（かならず 1かいだけ！）

② かめ プログラム（したの わく）

  • up(n) — うえに n マス すすむ
  • down(n) — したに n マス すすむ
  • left(n) — ひだりに n マス すすむ
  • right(n) — みぎに n マス すすむ
  • eat() — いま いる ばしょの たべものを たべる

💡 たべものの うえを とおっても、eat() と かかないと たべないよ！

💡 # これはメモだよ のように # を つかうと メモが かけるよ。

💡 マスの ばんごうは 1〜10 だよ。x は みぎ、y は した むきに すすむよ。
